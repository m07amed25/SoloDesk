## Constitutional and release limits

The implementation keeps database handles, keys and paths in the main process (Principle II), refuses plaintext fallback and empty replacements (V/VII), provides bilingual recovery controls (VI), and records local verification separately from release assurance (VIII). The outbox is local only; cloud authority and cross-device reconciliation have not been proved. No customer business records were persisted by these tests.

The code cannot establish a secure-erasure guarantee for SQLite/native process buffers; `Buffer.fill(0)` covers owned key buffers and native handles are closed. A fluent Arabic accessibility review and Windows/macOS/native keyring runs remain required before a supported release. F006's production consumption gate remains blocked.
