# F009 implementation and QA evidence

Date: 20 October 2026. Status: **partial synthetic implementation; production acceptance incomplete**.

The original seven suites contain 40 tests (including parent tests). Five additional regression tests cover transaction membership changes, audit grant scope, unknown audit projections, and gateway verified-context admission/precise bigint serialization/receipt archival immutability, and exact persistence above Number.MAX_SAFE_INTEGER.

Local verification after fixes:

- 45/45 F009 tests pass using Node's test runner with isolation disabled; suite evidence is generated by `npm run test:f009` in `.verification/f009-evidence.json`.
- Repository TypeScript and lint checks pass. The changed F009 service/test files also receive a focused lint check because repository lint excludes Edge Function source and F009 test paths.
- Documentation link checks pass.

The runner explicitly selects TAP output, counts summary results, and fails on child-process errors, absent files, or zero tests. A sandbox child-process failure must not become a passed scenario.

## Limits and remaining acceptance

Tests use an in-memory SQLite emulator, not PostgreSQL or a Supabase deployment. They verify synthetic revision changes rather than real business mutations. Concurrent Promise submissions are not independent database transactions or lock/deadlock verification. Recovery tests set write state manually; they do not detect restored evidence corruption. Dictionary checks do not render UI, ARIA live regions, RTL layouts, or screen readers.

The migration has table/trigger scaffolding but no authoritative transaction, reconciliation, or audit query functions. It has not been applied or tested against PostgreSQL in this work. The production database adapter, credential verifier, current per-action/resource authorization, F003 response envelope integration, duplicate-key transport decoding, audit query/export service, original-digest reconciliation fences and recovery verifier remain incomplete. Existing F008 authentication helpers also contain pre-existing TypeScript errors excluded from the repository compiler configuration; a focused gateway dependency compile exposes them.

Earlier claims of PostgreSQL schema verification, full quickstart execution, native UI acceptance, and complete security/regression coverage were unsupported by these tests and have been removed.
