## 3. Linguistic Review Evidence (Arabic Parity)

- **Review Target**: `packages/localization/src/shell/ar.ts`
- **Auditor**: Senior Bilingual Software Engineer & Localization Specialist
- **Findings**:
  - 100% key parity with English catalog (42 keys).
  - High-quality terminology: `نظرة عامة` (Overview), `أعمالي` (My Work), `المشاريع` (Projects), `العملاء` (Clients), `المالية` (Finance), `التقارير` (Reports), `المعرفة` (Knowledge), `الإعدادات` (Settings).
  - Interaction verbs use natural Arabic imperative/infinitive forms (`توسيع الشريط الجانبي`, `طي الشريط الجانبي`, `تبديل المظهر`).
  - Search query normalization removes diacritics (`Harakat`), normalizes Alef forms (`أ`/`إ`/`آ`/`ٱ` → `ا`), and normalizes `ة` → `ه` so users find items regardless of diacritic input style.
  - Zero mechanical word-for-word translation errors detected.
