## PostgreSQL & Hosted Supabase Database Verification

- **Migration Script**: `supabase/migrations/20261021000012_f012_workspace_creation.sql`
- **Objects Created**:
  - `workspace_tenants`: UUIDv4 production IDs, `display_name` (1–120 Unicode scalars, no controls), `readiness_state` (`setup_incomplete` default), and existing workspace status.
  - `workspace_memberships`: composite primary key `(workspace_id, user_id)`, closed role and membership status constraints.
  - `workspace_creation_intents`: unique client intent UUIDv4, request payload digest, status machine (`submitted`, `committed`, `proven_not_created`, `rejected`, `outcome_unknown`), idempotency guarantee.
  - `tenant_audit_events`: immutable audit stream with `workspace_created` and `workspace_switched` events.
  - RPCs: `solodesk_workspace_bootstrap`, `solodesk_create_workspace`, `solodesk_reconcile_workspace_creation`, `solodesk_list_selectable_workspaces`, and `solodesk_check_workspace_selectability`.
- **Privilege Boundaries**:
  - RLS enabled and forced on all public tenant tables; private creation tables have all direct `PUBLIC`, `anon`, and `authenticated` privileges revoked.
  - `anon` has zero access to tables or RPCs.
  - Direct inserts blocked for `authenticated`; creation permitted strictly via atomic security-definer RPCs deriving actor from `auth.uid()`.
  - Non-enumerating responses: missing, foreign, suspended, or revoked targets return indistinguishable `workspace_unavailable`.
- **Rollback Proof**:
  - Tested in `tests/f012/integration/rollback.test.mjs`.
  - Disabling RPC grants or creation policy safely shuts down creation while leaving old rows, memberships, audit events, and SQLite partitions intact.
- **Hosted Status**: Schema and approved creation policy deployed to the production Supabase PostgreSQL 17 database in `eu-west-1`. All 13 migration versions are recorded. F012 RPCs deny `anon` and grant `authenticated`; `f012_v1_prod` is the sole active policy with `en`/`ar`, IANA timezones, and `EGP`, `USD`, `EUR`, `GBP`, `SAR`, `AED`. Production contains zero synthetic policies.
