# Domain glossary and Arabic terminology seed

Proposed product terminology; Arabic wording needs fluent product/finance review before release. Stable enum/type identifiers are language independent. This is not a legal translation certificate.

| Term | Meaning in SoloDesk | Arabic seed |
| --- | --- | --- |
| Account | Person's authenticated identity across workspaces | حساب |
| Workspace | Tenant/business boundary, with members and records | مساحة عمل |
| Member / guest | Internal authorized user / externally scoped client reviewer | عضو / ضيف |
| Client / contact | Contracting business/person / communication identity | عميل / جهة اتصال |
| Opportunity | Potential engagement, not contracted income | فرصة عمل |
| Estimate / proposal | Pricing/effort scenario / versioned commercial offer | تقدير / عرض |
| Agreement / scope baseline | Recorded accepted terms / versioned delivery commitment | اتفاقية / نطاق عمل معتمد |
| Milestone / deliverable | Planned outcome checkpoint / versioned output for review | مرحلة رئيسية / مخرج عمل |
| Billable time | Eligible reviewed work, not necessarily issued or paid | وقت قابل للفوترة |
| Reservation / allocation | Draft claim acknowledged by server / committed consumption of source | حجز / تخصيص |
| Invoice draft / issued invoice | Editable preview / immutable numbered obligation | مسودة فاتورة / فاتورة مُصدرة |
| Credit note / refund | Document reducing obligation / cash returned | إشعار دائن / استرداد مبلغ |
| Settlement / outstanding | Value applied to obligation / unpaid remainder | تسوية / رصيد مستحق |
| Retainer | Explicit prepaid money or service allowance agreement | اتفاق أتعاب مقدم |
| Revenue / collected cash | Declared report basis / actual received funds | إيراد / مبالغ محصلة |
| Saved locally / synchronized | Durable on this device / accepted by cloud authority | محفوظ محليًا / تمت المزامنة |
| Conflict / rejected operation | Divergent candidates / write denied by current server rules | تعارض / عملية مرفوضة |
| Archive / tombstone / purge | Hide reversibly / retained deletion marker / permanent removal under retention | أرشفة / علامة حذف / حذف نهائي |
| Audit / provenance | Who did what and why / origin/evidence of data | سجل تدقيق / مصدر البيانات |

Do not use “Paid” for merely sent invoices, “Verified signature” for owner-entered notes, “Saved” for an uncommitted form, or “Profit” for unqualified operational forecasts. Use the [UX contract](ux-and-localization.md) for locale/input/bidi rules.
