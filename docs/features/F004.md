# F004 — Secure Electron lifecycle and preload bridge

F004 implements the [tracked specification](../../specs/004-secure-electron-lifecycle/spec.md) and [plan](../../specs/004-secure-electron-lifecycle/plan.md) for the existing desktop shell. [Observed QA](../qa/F004.md) records the candidate checks and open native review. F003's merged version-1 bounds and error vocabulary are consumed by the desktop boundary.

## What the shell does

The main process acquires Electron's app-wide single-instance lock before creating a profile context. A losing process transfers only a closed, bounded activation and exits. The owner keeps one in-flight window creation per app-known local profile. Production enables the default profile; synthetic A/B profiles are available only to the isolated desktop test harness. Profile IDs are routing labels and never workspace authority.

Every profile view gets a distinct nonpersistent Chromium session. Release content loads from the asset-only secure `solodesk-app://ui` origin. Development uses only the exact local Forge loopback origin. The view remains sandboxed, context isolated, without Node integration or a renderer IPC handle. Permissions, new windows and unplanned navigation deny by default.

The sandboxed preload exposes a frozen `window.solodesk` facade:

| Family | Methods | Boundary |
| --- | --- | --- |
| `window` | `getState`, `minimize`, `restore`, `requestClose` | Current trusted window only |
| `lifecycle` | `onState` | Bounded state events; returns unsubscribe |
| `links` | `onDecision` | Safe accepted/denied/unavailable notices; returns unsubscribe |

Each action uses a closed version-1 request with a tagged F003 request ID and empty payload. Main copies and validates data before checking the exact webContents, live top-level frame, origin, document, profile epoch and current authority. Unknown fields, versions, callers and contexts deny before native effect. Results expose no path, token, database access, raw channel or protected record. An uncertain native outcome says `outcome_unknown`, never a fabricated not-applied result.

## Links and lifecycle

The only production app link is `solodesk://open/home`. It is parsed as untrusted input at initial launch, second launch and macOS `open-url`; the same maximum length, grammar and profile checks apply. Synthetic record routes exercise authority denial, while production record routes and auth callbacks remain unavailable. The external-purpose catalogue is empty, so no renderer URL reaches the OS opener. F010/F029 own sign-in callbacks and packaged registration.

On Windows and Linux, closing the last window quits after the drain coordinator settles or explicitly interrupts synthetic in-flight work. On macOS, closing the last window leaves the process ready; dock activation recreates the default view. Explicit Quit drains once on every platform, rejects new privileged requests and disposes subscriptions. The provisional drain budget is five seconds. No tray, hidden timer, customer database migration, encrypted cache or durable business-work recovery is claimed here; Q-04 and later feature owners define those policies.

Failure never creates an empty replacement protected profile. The app shows safe restart guidance in English and Arabic and exits. Window/link denials use paired safe guidance in the shell; F005 owns the complete bilingual interface.

## Verification and limitations

Run `npm run test:f004`, `npm run typecheck`, `npm run lint`, `npm run build` and `npm run test:desktop` after the documented Electron setup. The verification manifest enrolls F004 unit/integration and the built Electron cases alongside F002/F003. The desktop suite requires a real native host; a Linux result is not a Windows or macOS result. The Linux Snap integrated-terminal regression, fluent Arabic review, 100 native process races per target and Q-11 final support matrix remain evidence gates in [F004 QA](../qa/F004.md).

The bridge and link shapes are versioned. A later feature must add an individually reviewed method/route with current identity, workspace and resource authority, tests and a declared upgrade path. No generic domain dispatcher or arbitrary URL is available.
