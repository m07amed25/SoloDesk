## Operations, Rollback & Secret Redaction Guidance

- **Zero-Secret Boundary**: Passwords, TOTP seeds, QR codes, recovery codes, tokens, cookies, and raw provider errors must NEVER cross native IPC or appear in logs/evidence.
- **Rollback Behavior**: If the policy factor requirement is set to `unavailable`, entry points in the UI are cleanly hidden while preserved local credentials and encrypted data remain intact on disk.
- **Missing Local Keys**: Cloud identity recovery never claims to decrypt local SQLite/file bytes when local keys are missing (`local_unlock_required`).
- **Support Route**: When unrecoverable or locked out, users must follow the support protocol defined in `docs/qa/F011-usability-protocol.md`.
