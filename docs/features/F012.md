## Implementation Overview

F012 establishes truthful workspace creation defaults and safe local switching without cross-tenant signals or data redirection. It enforces:

- **Canonical UUIDv4 Workspace IDs**: All created workspaces use bare lowercase UUIDv4.
- **Truthful Readiness State**: Workspaces start in `setup_incomplete`; legal and trade names are optional profile fields, and display names are never treated as legal or permission authority.
- **Sole Creator Owner**: Atomic creation establishes exactly one active Owner membership for the verified account.
- **Idempotent Intent Reconciliation**: Repeated submissions with the same client intent UUID reconcile cleanly without duplicate workspace or membership creation.
- **Single WorkspaceCoordinator per Profile**: Monotonic `selectionGeneration` fences all requests, DTOs, background events, and dialog confirmations.
- **Safe Switching Protocol**: Unsaved editor memory is resolved before leaving (stay, discard, or save to source); durable work retains source tenant ownership; target selectability is checked online; source partition is closed and target opened in retained-only mode.
- **Fail-Closed Boundaries**: Missing, locked, unreadable, incompatible, offline, or revoked states fail closed without creating empty replacement databases.
- **Bilingual Accessibility**: Full English and Arabic meaning parity, authentic Arabic script, bidi text isolation with `<bdi>`, focus trapping, and 200% zoom reflow.

## Operations, Rollback & Secret Redaction Guidance

- **Zero-Secret Boundary**: Tokens, credentials, SQLite encryption keys, filesystem paths, raw errors, and hidden tenant metadata must NEVER cross the Electron bridge or appear in logs/evidence.
- **Rollback Behavior**: If the F012 creation policy or RPC grants are disabled, existing workspaces, memberships, intents, and local encrypted partitions remain preserved and intact on disk.
- **Hosted Policy State**: Production has exactly one enabled policy (`f012_v1_prod`) and zero synthetic/test policies. Disabling that policy returns creation to the fail-closed state without deleting existing workspaces.
- **Partition Integrity**: `openRetainedWorkspace` never creates a blank database on corruption, missing files, or binding mismatch.
- **Support Route**: When unrecoverable or locked, users follow the protocol defined in `docs/qa/F012-usability-protocol.md`.
