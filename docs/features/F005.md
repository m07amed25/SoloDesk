# F005 — Accessible English/Arabic Application Shell

F005 implements the foundational desktop user interface shell for SoloDesk in accordance with the [tracked specification](../../specs/005-accessible-application-shell/spec.md), [implementation plan](../../specs/005-accessible-application-shell/plan.md), and [design tokens](../../docs/design/tokens.json). [F005 QA evidence](../qa/F005.md) records unit tests, accessibility verifications, and cross-platform evidence gates.

---

## 1. Architectural Summary & Delivered Capabilities

1. **Bilingual Parity & Full RTL Layout (PLT-015, NFR-006)**:
   - Root direction dynamically synchronizes between `ltr` and `rtl` based on active locale (`en` vs `ar`).
   - Approved typography: `Inter` for Latin script, `Noto Sans Arabic` with adequate line height (`1.625`) for Arabic diacritics.
   - Bidirectional text isolation (`<BdiText>`, Unicode `\u200E` marks) protecting mixed identifiers (`INV-2026-001`), emails, and monetary tokens against inverted punctuation.
   - Operating system window controls preserve platform physical placement in RTL (`dir="ltr"` anchored to physical top-right on Windows/Linux; macOS top-left margin).

2. **100% Keyboard Reachability & Accessibility (NFR-007, WCAG 2.2 AA)**:
   - Visible, high-contrast focus rings (minimum 2px solid with ≥ 3:1 contrast against adjacent backgrounds).
   - "Skip to main content" link at the beginning of the tab order targeting `<main id="main-content">`.
   - Standard semantic ARIA landmarks (`<header role="banner">`, `<nav role="navigation">`, `<main id="main-content" role="main">`).
   - Suppressed animations and instant transitions under `@media (prefers-reduced-motion: reduce)`.

3. **Global Command Palette (PLT-015)**:
   - Modal dialog invokable via `Mod+K` (`Cmd+K` on macOS, `Ctrl+K` on Windows/Linux) and header search trigger.
   - ARIA `role="combobox"` with `aria-autocomplete="list"` and `aria-activedescendant`.
   - High-performance query normalization and filtering (< 50ms across 100+ actions).
   - Arabic normalization stripping Tashkeel diacritics, unifying Alef variants, and normalizing Ta Marbuta.
   - Automatic focus restoration to trigger element upon dismissal.
   - Strict protection against intercepting OS-reserved shortcuts (`Alt+F4`, `Cmd+Q`, `Win+L`, `Ctrl+Alt+Del`).

4. **Appearance & Theme Management**:
   - Supports Light, Dark, and System display modes using paired tokens from `tokens.json`.
   - Persistent `prefers-color-scheme` listener synchronizing with operating system dark mode.
   - Windows Forced Colors high-contrast support using system color tokens (`ButtonBorder`, `Highlight`).
   - Fluid 200% zoom reflow down to 1024×768 CSS pixels without horizontal scrollbars.

5. **Honest Navigation & Foundation Placeholders**:
   - 9 canonical routes (`overview`, `my-work`, `projects`, `clients`, `time`, `finance`, `reports`, `knowledge`, `settings`).
   - Collapsible sidebar rail (expanded 240px, collapsed 64px with accessible `@base-ui/react` tooltips).
   - Accessible breadcrumb hierarchy with directionally mirrored chevron separators.
   - Truthful placeholders for upcoming foundation capabilities (`F012` Workspaces, `F036` Timer, `F017` Sync status, `F022` Notifications) containing zero simulated revenue or fake records.
   - Active Settings view exposing display preferences and desktop environment runtime details.

## 2. Unprivileged Security Boundaries (Principle II & V)

- The renderer process runs completely unprivileged and sandboxed with no Node.js access (`process`, `require`, `fs`).
- Communication with the desktop runtime occurs exclusively through the narrow typed bridge `window.solodesk` established in F004.
- Corrupted or unparseable user preferences fail closed to safe defaults (`en`, `system`, expanded sidebar) without throwing unhandled exceptions.
