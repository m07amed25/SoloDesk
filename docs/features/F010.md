## Implementation Entry Decisions and Gates

F010 establishes trusted browser sign-in and first native device enrollment. Production cloud delivery remains blocked behind explicit owner/product release gates. Local implementation is developed and verified against synthetic and sandbox fixtures:

1. **Approved Sandbox Method**:
   - Single configured sandbox method (`authorization_code` with PKCE S256).
   - Public registration, self-serve sign-up, and production identity providers remain disabled.
2. **Expected Issuer and Audience**:
   - Sandbox Issuer: `https://auth.solodesk.test` (or configured Supabase auth endpoint).
   - Application Audience: `solodesk-desktop`.
   - Verified Account Identity: strictly `(issuer_id, subject_id)`. Email and display name are non-authoritative.
3. **Hosted Origin and Start Purpose**:
   - Hosted Origin: `https://auth.solodesk.test` (exact HTTPS allowlist).
   - Start Purpose: desktop main constructs URL and invokes `shell.openExternal`; renderer cannot specify arbitrary URLs.
4. **Callback Transport and Destination**:
   - Sandbox Transport: Ephemeral loopback IP (`http://127.0.0.1:<port>/auth/callback`) with single-request lifecycle, and private-use scheme (`solodesk://auth/callback`) parser for desktop ingress.
   - Destination Identifier: `desktop_loopback_v1` / `desktop_custom_scheme_v1`.
   - Wildcards, arbitrary redirects, and user-specified `return_to` are strictly prohibited.
5. **Attempt, Bounds, and Rate Policy**:
   - Attempt Lifetime: 300 seconds (5 minutes). Exactly one active `pending` attempt per `(profile_id, profile_generation)`.
   - Maximum Callback Query Payload: 2048 bytes.
   - Device Label: bounded to 64 UTF-8 characters; non-authoritative.
   - Ingress validation enforces constant-time comparisons for proof digests and rejects duplicates/fragments/unknown fields.
6. **Disposition of Open Release Gates**:
   - **Q-02 (Hosted region, budget, and limits)**: Open gate. Production hosting infrastructure is not provisioned.
   - **Q-07 (Protected credential storage approval)**: Open gate. Main-only protected adapter uses the F006 `ProtectionOwner` boundary; plaintext fallback is prohibited.
   - **Q-08 (Production authentication policy and MFA/recovery)**: Open gate. Additional production identity methods, MFA, and recovery belong to F011 and owner approval.
   - **F029 (Packaged protocol registration proof)**: Open gate. OS packaged installer protocol handling for Windows, macOS, and Linux requires final build and packaging verification.
   - **Production Delivery Status**: Blocked for production deployment. Local execution proceeds for unit, integration, service atomicity, UI parity, and emulator validation.
