Pure APIs live under `packages/domain/src`, `packages/contracts/src` and `packages/localization/src`, without dependencies or Node/DOM ambient types. Import only the required source module. Constructors return immutable `Result<T>` values, accept canonical ASCII numeric text, and normalize only when explicitly documented; wire admission is strict. Example: `integerOp('9007199254740993','1','add')` returns exact `9007199254740994`; `toDecimal({numerator:'1',denominator:'3'})` returns `non_representable`. No conversion rounds. Use `moneyOp` only with matching currency/exponent/profile/adjustment kind. Use `request(input, trustedRegistry)` before a future boundary resolves actual ownership and authority.
