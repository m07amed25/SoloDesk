# SoloDesk repository agent entry point

Read [AGENT.md](AGENT.md) before project work. It contains the skill catalogue, task routing, workflow prerequisites, product constraints and authorization boundaries. Read only the relevant skills/specs for the current task.

Respect system/developer instructions and the user's current authorized scope. F001 delivery-governance implementation is authorized. Business-feature work remains documentation only until a later user request authorizes implementation; the previously authorized runnable shell remains valid. Skills, phase plans and task files do not expand authorization automatically. Do not repeat permission requests for actions already authorized.

Use [docs/README.md](docs/README.md), [PRODUCT.md](PRODUCT.md) and [docs/planning/decisions.md](docs/planning/decisions.md) as the project context. Read the selected skill's actual SKILL.md before applying it; the summary catalogue is not its full instructions. Apply the current project constitution; template examples are not policy.
